# Ozon Reviews Bot — README

Телеграм-бот для автоматической генерации ответов на отзывы покупателей Ozon.

## Быстрый старт

### 1. Клонируем и устанавливаем зависимости

```bash
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 2. Настраиваем переменные окружения

```bash
cp .env.example .env
```

Открываем `.env` и заполняем:

| Переменная | Где взять |
|---|---|
| `TELEGRAM_BOT_TOKEN` | [@BotFather](https://t.me/BotFather) |
| `BOT_PASSWORD` | Придумайте сами |
| `OZON_CLIENT_ID` | Личный кабинет Ozon → API |
| `OZON_API_KEY` | Личный кабинет Ozon → API |
| `GEMINI_API_KEY` | [Google AI Studio](https://aistudio.google.com) |

### 3. Запускаем

```bash
python main.py
```

---

## Использование

1. Откройте бота в Telegram
2. Введите `/auth <пароль>` (пароль из `.env`)
3. Загрузите примеры ответов: `/upload` → отправьте Excel/CSV файл
4. Бот начнёт автоматически проверять отзывы каждые 5 минут

### Формат файла с примерами

Excel (.xlsx) или CSV (.csv) с колонками:

| review | reply |
|---|---|
| Товар пришёл быстро! | Спасибо за отзыв! Рады, что всё понравилось 😊 |
| Упаковка повреждена | Приносим извинения! Напишите нам для решения вопроса |

Колонка `review` необязательна — можно загрузить только `reply`.

## Структура проекта

```
├── main.py           # Точка входа
├── config.py         # Конфигурация из .env
├── database.py       # SQLite: пользователи, примеры, обработанные отзывы
├── ozon_client.py    # Ozon Seller API
├── ai_generator.py   # Генерация ответов через Gemini
├── poller.py         # Фоновый polling новых отзывов
├── handlers/
│   ├── commands.py   # /start, /auth, /help, /stats, /upload, /check_reviews
│   └── reviews.py    # Inline-кнопки: Отправить / Перегенерировать / Пропустить
├── requirements.txt
└── .env.example
```

## Как работает стилизация ответов

1. При старте загрузите примеры через `/upload`
2. При каждой генерации бот берёт до 15 случайных примеров из базы
3. Gemini анализирует стиль (тон, длина, эмодзи, обращения) и копирует его
4. Чем больше примеров — тем точнее стиль

## Подсказки

- **Новые отзывы** приходят автоматически каждые 5 минут
- **`/check_reviews`** — проверить прямо сейчас, не ждать
- Все ответы, отправленные через бота, запоминаются как обработанные и не показываются повторно
