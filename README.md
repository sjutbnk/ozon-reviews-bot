# Ozon Reviews Bot

Внутренний Telegram-бот для работы с отзывами Ozon.

## Запуск

```bash
uv venv .venv
uv sync
uv run playwright install chromium
cp .env.example .env
# заполните TELEGRAM_TOKEN и AUTH_PASSWORD в .env
uv run python main.py
```

Без реального `TELEGRAM_TOKEN` Telegram отклонит подключение, и `/start` работать не будет.

## Суть

- получает новые отзывы из Ozon;
- собирает черновики ответов;
- показывает их в Telegram;
- позволяет отредактировать, пересоздать, пропустить или отправить ответ;
- запоминает стиль по загруженным примерам.

## Как это выглядит

1. Бот находит новый отзыв.
2. Генерирует черновик ответа.
3. Отправляет карточку в Telegram с кнопками действий.
4. Менеджер правит текст или публикует его в Ozon.

## Интерфейс в Telegram

- `/auth <пароль>` — открыть доступ
- `🔎 Проверить отзывы` (/check) — запустить поиск новых отзывов вручную
- `🎨 Стиль ответов` (/examples) — добавить CSV/XLSX с примерами стиля
- `🔐 Ozon-сессия` (/session) — инструкция и проверка сессии Ozon
- `📊 Статистика` (/stats) — статус сессии и количество примеров стиля
- `❌ Отмена` (/cancel) — отменить текущее действие

## Подключение Ozon

Бот работает на сервере в Docker и подключается через экспорт сессии браузера:

1. Установите расширение **Cookie-Editor** ([Chrome](https://chromewebstore.google.com/detail/cookie-editor/hlkenndednhfkekhgcdicdfddnkalmdm) / [Firefox](https://addons.mozilla.org/ru/firefox/addon/cookie-editor/)).
2. Войдите в [seller.ozon.ru](https://seller.ozon.ru/).
3. В Cookie-Editor нажмите **Export** → **Export as JSON**.
4. Отправьте скопированный текст или `.json` файл боту в Telegram.

Бот автоматически проверит валидность сессии и сразу начнет опрос отзывов.

## Акценты

Проект рассчитан на аккуратную ручную модерацию:

- без лишней автоматизации;
- без скрытых действий;
- с понятным черновиком перед публикацией;
- с повторяемым стилем ответов.
